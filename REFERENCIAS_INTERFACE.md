# Princípios de interface do Projeto IA

As telas do aplicativo seguem a identidade visual própria do Projeto IA e priorizam fluxos simples para configurar provedores, testar modelos, conversar e administrar projetos.

- Seletores devem mostrar nomes claros, disponibilidade conhecida e avisos de custo quando necessário.
- O seletor de modelo deve ficar próximo ao campo de mensagem e valer para a conversa aberta.
- Recursos avançados devem explicar o efeito antes de alterar credenciais, cobrança, arquivos ou comandos.
- Novos elementos devem seguir os componentes Compose e os recursos de tema já usados pelo aplicativo.
- A lista de repositórios deve reunir clones encontrados nos projetos e oferecer instalação por URL Git pública.

Consulte `README_PROJETO_IA.md` para o estado atual e as limitações conhecidas.
