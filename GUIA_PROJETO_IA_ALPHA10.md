# Projeto IA — 0.1.0-alpha10

## Linux no menu

1. Instale o APK e confira `0.1.0-alpha10` em Sobre.
2. Abra **Linux** no menu lateral, na página inicial ou na lista de Projetos.
3. Toque em **Baixar Linux para todos os projetos** e mantenha o app aberto durante a preparação.
4. Acompanhe os bytes recebidos, a extração, a instalação das ferramentas, o tempo decorrido e a última atividade. Os detalhes mostram a saída da instalação. É possível cancelar e tentar novamente.
5. Quando aparecer **Ambiente compartilhado pronto**, crie os próximos projetos em Projetos ou Programação.

Todo novo projeto local usa automaticamente a mesma instalação. Projetos criados antes do término do download também passam a encontrar esse Linux quando a preparação termina. Reabrir o app ou excluir um projeto não exige outro download. Excluir os dados do aplicativo remove a instalação local.

O Linux e as ferramentas instaladas no sistema são compartilhados. Cada projeto mantém arquivos, pasta pessoal e temporários separados. Dependências salvas dentro de um projeto ou de sua pasta pessoal pertencem àquele projeto.

A seção Linux de um novo projeto abre **Gerenciar Linux compartilhado**, evitando um segundo instalador por projeto. O painel Programação usa a mesma preparação e o mesmo progresso da tela Linux.

Esta versão concentra o acesso no menu e o fluxo dos próximos projetos. Ela não migra nem apaga ambientes anteriores.

## Vídeo e recursos pendentes

O importador de MP4 da alpha09 foi mantido. Para edição local, use Programação com um projeto ativo e anexe por **Vídeo para o projeto**. Reconhecer o anexo não instala HyperFrames ou FFmpeg. Claude Code e a edição completa pelo HyperFrames continuam sem homologação no telefone.

O novo relato de “unsupported file” ainda não foi reproduzido. Os testes anteriores do importador não comprovam o caminho usado no aparelho. Para localizar a falha, são necessários a versão instalada, a tela da mensagem atual e a opção utilizada para selecionar o arquivo.

Os resultados da compilação e dos testes desta entrega estão em `VALIDACAO_ALPHA10.md`. Não houve teste de interface ou instalação no Poco F7.
